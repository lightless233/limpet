# Plan 001：tmux 会话接续与终端会话列表

- 日期：2026-11-22
- 对应 Spec：`docs/specs/001-2026-11-22-tmux-sessions-and-terminal-list.md`
- 执行方式：INLINE，单人单会话
- 依赖顺序：U1 → U2 → U3 → U4（U2 依赖 U1 的 tmux 语义；U3 依赖 U2 的 API）

## 单元 1：tmux 宿主替换直接 PTY

**问题**：`server/term.go` 的 `spawnShell` 直接启动 zsh，WS 断开即杀进程，无接续能力。

**改动**：PTY 子进程从 Shell 换成 tmux 客户端进程。会话首次接入（首条尺寸消息到达）时：会话不存在则 `tmux -L limpet -f <limpet-conf> new-session -s <id> -x -y`，已存在则 `attach -t <id>`。WS 断开只杀客户端进程，不再触碰会话。tmux 会话的创建从接入时机移到创建接口（见单元 2，本单元先保持「接入时创建」的现有结构跑通，单元 2 调整为创建即建）。会话结束监视器语义改为：tmux 会话消失（Shell 内 exit / kill-session）→ 关闭当前客户端连接。

**保持不变**：帧协议、首条尺寸消息启动、ready 帧、1008 拒绝、claimed 单接入 409、TTL 预留、尾部清理（未启动回收改为回收「预留条目」，tmux 会话不存在时同样成立）、每会话重建前端 core。

**边界**：Limpet 专属 tmux 配置文件与 `-L limpet` socket 由本单元引入；配置内容（escape-time、history-limit）在本单元定稿。

**完成证据**：现有帧级协议测试在 tmux 模式下全部通过（协议不变性）；新增验证——attach 后 `tmux list-sessions` 可见、断开 WS 后会话仍存在且客户端进程消失、Shell 内 exit 后会话消失且客户端被关闭。

## 单元 2：会话管理 API（创建/列表/重命名/关闭）

**问题**：现在只有「预留 + 接入」，没有列表，创建时机不产生可见会话。

**改动**：
- `POST /api/term` 接受可选 `name`：校验字符集（禁 `:` `.`、长度 ≤ 100）与重名（409），创建即 `tmux new-session`（Shell 随会话启动），返回 id。预留（未接入）与 tmux 会话并存：预留条目承载「已创建待接入」状态，TTL 语义不变。
- `GET /api/term`：从 `tmux list-sessions` 实时映射（id/created/attached），创建时间倒序；预留未接入的条目同样列出。
- `POST /api/term/{id}/rename`：校验 + 409 语义同创建。
- `POST /api/term/{id}/close`：kill-session + 清理预留条目；会话不存在 404。
- tmux 可用性检查：socket 不可用统一 503 + 原因。

**完成证据**：帧级/HTTP 测试覆盖——创建即出现在列表、重名 409、非法字符拒绝、rename 后旧名 404 新名可接入、close 后 Shell 进程消失且列表移除、close 已消失会话 404、列表在 Go 重启后从 tmux 重建。

## 单元 3：前端会话列表与切换

**问题**：前端是单终端页，无法并行多任务。

**改动**：列表视图（移动端即首页）：名称/创建时间/接入状态，操作为新建（弹层输入名称，可空）、打开、关闭（确认框）、重命名；进入终端页复用现有组件与生命周期（每会话重建 core、ready 闸门、inert）。终端页提供「返回列表」；返回不断开后台。切换会话 = 回列表再点开另一项。列表数据在进入页面与每次增删改后刷新。

**完成证据**：`pnpm build` 通过 + 浏览器手测清单（spec 验收 1/2/4/5/6 的 UI 路径）。

## 单元 4：验收整合

**改动**：按 spec 验收标准 1–9 逐条执行帧级与 HTTP 测试；手机接入场景（验收 10）留给用户按 charter 验收方式执行。清理测试脚本中对直接 PTY 时序的遗留假设。

**完成证据**：全部自动化项通过 + 供用户执行的手测清单（含手机场景步骤）。

## 风险与备注

- tmux 客户端进程的 PTY 与 tmux 会话尺寸的协商行为依赖 tmux 版本（3.3a 已确认），若首屏尺寸出现偏差，优先调 `-x/-y` 传参而不是改协议。
- 用户个人 tmux 环境（`~/.tmux.conf`、默认 socket）与本方案完全隔离，不存在迁移问题。
- 直接 PTY 模式退役无兼容层（spec 已声明），切换时现存临时测试会话自然失效。
